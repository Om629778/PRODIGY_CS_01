# PRODIGY_CS_01 - Caesar Cipher Tool

This project is a simple Caesar Cipher program developed in Python. It allows users to encrypt and decrypt messages using a custom shift value. The tool also includes a brute-force attack feature to test all possible decryptions.

## Features
- Encrypt messages
- Decrypt messages
- Brute Force Attack
- User-friendly menu interface

## Technologies Used
- Python 3

## Run the Program

```bash
python internshiptask1cs.py
```
